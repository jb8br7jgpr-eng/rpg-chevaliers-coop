Deux chevaliers.
Une quête.
Un trésor.

Un RPG médiéval-fantastique conçu pour deux joueurs qui voyagent toujours ensemble. Choisissez votre quête, combinez vos talents, déchiffrez les indices et trouvez votre chemin jusqu'au trésor.

Statut : règles en cours de finalisation. Cette page documente le projet ; le jeu n'est pas encore développé ni jouable ici.

2chevaliers inséparables
120points de caractéristiques chacun
9–12étapes principales
8compétences disponibles

Une aventure qui se construit à deux

Chaque expédition commence dans une ville, avec une bourse commune de 200 pièces d'or. La taverne propose trois quêtes tirées au sort parmi les destinations disponibles.

🗺️ Explorer et déduire

Trois indices principaux garantis guident vers le trésor. Deux ou trois grands embranchements proposent plusieurs itinéraires, dont un seul correct. Les chemins facultatifs cachent risques et récompenses.

🎲 Combattre ensemble

Chaque chevalier lance un D20 augmenté de son bonus Attaque + Défense. On conserve le meilleur résultat du duo face à l'ennemi. Les cœurs perdus sont précieux ; les boss exigent trois victoires de duel.

💎 Trouver le vrai trésor

Dans 70 % des expéditions, la finale oppose les chevaliers à un boss ; dans les autres, à une énigme. Surmonter l'épreuve ne suffit pas : il faut encore identifier la cachette du trésor et le récupérer.

Un système documenté pour ne rien perdre

Le journal d'aventure prévu dans le jeu conserve automatiquement les indices, les lieux, les combats, les rencontres et les découvertes. Pour le développement, ce dépôt joue le même rôle : il conserve les décisions prises.

Document officiel : REGLES_COMPLETES_RPG_COOP.txt

Les règles validées, les huit compétences, les équipements, les prix, les formules, les probabilités, les conditions de victoire et les décisions encore ouvertes sont détaillés dans le fichier texte.

Chaque nouvelle règle acceptée doit être ajoutée au document par un nouveau commit GitHub, afin de garder l'historique des versions.
